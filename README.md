# java-CharCounter
Код на языке JAVA для условия задачи: Напишите программу рассчитывающую количество вхождений символа в строку.

str_count("Hello", 'o'); // вернет 1
str_count("Hello", 'l'); // вернет 2
str_count("", 'z'); // вернет 0

Запустить командную строку и написать в поле любую фразу, например: Hello world.

В следующей строке указать какой символ нужно рассчитать (сколько раз встречается в тексте).

Получаем ответ и готово.
